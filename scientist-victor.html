Виктор Крейн

Ведущий научный сотрудник | Отдел нейропротезирования

Специалист по нейромодуляции и спинальной нейропротезике

О себе

Стаж работы: 9 лет

Образование: Гарвардская медицинская школа, программа по нейроинженерии (2010)

Учёная степень: Доктор наук (ScD) по нейропротезированию

Направление: Системы замкнутого цикла для модуляции ноцицептивных путей

Ключевые достижения

  • Разработал имплантируемый нейромодулятор для селективной блокады болевых сигналов на уровне задних рогов спинного мозга без системных побочных эффектов
  • Создал алгоритм адаптивной нейростимуляции, восстанавливающий ходьбу у пациентов с неполным повреждением спинного мозга
  • Впервые реализовал беспроводную систему замкнутого цикла для мониторинга и подавления хронической нейропатической боли в реальном времени
  • Запатентовал метод оптогенетической модуляции спинальных нейронов, позволивший точечно контролировать болевые сигналы без хирургической замены имплантатов

Патенты и разработки

  • Патент RU 2601154 — Способ селективной эпидуральной нейромодуляции задних корешков спинного мозга
  • Патент RU 2601155 — Имплантируемая система замкнутого цикла для динамического подавления болевых сигналов
  • Патент RU 2601156 — Адаптивный алгоритм стимуляции спинного мозга для восстановления локомоторных функций
  • Патент RU 2601157 — Оптогенетический имплантат для точечной модуляции ноцицептивных нейронов

Участие в проектах Prisma Lab

  • Мио-Реактор XT — соавтор системы подавления болевых сигналов
  • Кардио-Контроллер SGN-4 — научный руководитель (разработка интерфейса мозг-спинной мозг)
